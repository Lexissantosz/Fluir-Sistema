# Fluir · Mockup

Branch acadêmica dedicada ao **mockup visual do Fluir**.

## Objetivo

Apresentar a experiência principal do produto em dois formatos com a mesma base responsiva:

- desktop / notebook;
- celular.

O mockup não depende de backend e utiliza dados fictícios para demonstrar navegação, hierarquia visual e principais fluxos.

## Fluxo demonstrado

1. Landing page
2. Login / cadastro
3. Configuração inicial
4. Dashboard
5. Tarefas
6. Hábitos
7. Água
8. Diário emocional
9. Configurações

## Como visualizar

Abra `index.html` com Live Server ou outro servidor estático. Redimensione o navegador para visualizar a versão mobile.

> Esta branch é isolada do projeto principal. Mudanças do mockup não devem ser mescladas automaticamente em `main`.
