# Fluir · MVP

Esta branch contém o **MVP funcional e responsivo** do Fluir.

## Escopo

O MVP foi reduzido para validar o núcleo da proposta:

- login e cadastro demonstrativos;
- configuração inicial;
- dashboard;
- tarefas;
- hábitos;
- hidratação;
- configurações;
- versão desktop e mobile na mesma aplicação responsiva;
- persistência local com `localStorage`.

## O que ficou fora

Recursos avançados do projeto completo, como finanças, sono, diário completo, anexos, ciclo menstrual, planos, conquistas e integrações de backend, não fazem parte deste MVP.

## Como executar

Abra `index.html` usando Live Server ou outro servidor estático.

O MVP salva os dados no próprio navegador. Isso permite demonstrar criação de tarefas, hábitos, registros de água, tema e preferências sem depender de servidor.

## Dados de demonstração

Na primeira execução, o sistema cria dados iniciais para que a apresentação não comece com telas vazias.

## Branches

- `main`: projeto completo
- `alex/mockup`: protótipo visual
- `alex/mvp`: produto mínimo funcional

Mudanças desta branch não devem ser mescladas automaticamente no projeto completo.
