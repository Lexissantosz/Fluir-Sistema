Quem você deseja acompanhar?

Você pode usar o módulo para seu próprio ciclo, acompanhar outra pessoa com autorização ou configurar isso depois.

Você deseja acompanhar o ciclo menstrual de mais de uma pessoa?

Isso significa alternar entre pessoas distintas. Não significa registrar vários ciclos da mesma pessoa.

O plano gratuito proposto contempla seu perfil e mais uma pessoa, ou apenas uma pessoa se você não acompanhar seu próprio ciclo. O limite definitivo ainda será aprovado.

Vamos personalizar seus perfis

Nome, apelido e foto são opcionais. Nenhum acesso de outra pessoa será concedido nesta prévia.

Como funcionará: a titular cria um convite de uso único e escolhe quem pode ver quais dados. Inserir o código não dá acesso por si só. Compartilhamento ainda não implementado.

Confira a configuração

Nenhum dado é enviado ou gravado. Este fluxo é somente um protótipo de interface para validação.

Para ativar compartilhamento real, são necessários backend autenticado, consentimento, escopos e testes de isolamento.
